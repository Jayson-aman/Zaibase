# App Store 掲載情報（ASO用）

`ja/` 配下のテキストファイルは、App Store Connect の「App 情報」「バージョン情報」画面にそのままコピー＆ペーストするための下書きです。コード（アプリ本体）には組み込まれません。App Store Connect が実際の提出先です。

| ファイル | 用途 | App Store Connect 上の文字数上限 |
|---|---|---|
| `name.txt` | App名 | 30文字 |
| `subtitle.txt` | サブタイトル（名前の下に表示） | 30文字 |
| `keywords.txt` | キーワード（非表示・検索用、カンマ区切り） | 100文字 |
| `description.txt` | 紹介文（冒頭3行が最重要） | 4,000文字 |
| `promotional_text.txt` | プロモーションテキスト（審査不要で随時更新可） | 170文字 |

## キーワード選定方針

在籍者数・受験者数が多く全国的に知名度の高い学校（灘・開成・慶應・早稲田・四天王寺・大阪桐蔭・日比谷・東大寺学園・甲陽学院など）のみを厳選して採用。地域色が強く受験者数が少ない学校（清風・高槻・関西大学北陽・帝塚山学院・金蘭会・プール学院・城星学園・大阪女学院・賢明学院・大谷・浪速・追手門学院・南山・東海・滝・久留米大学附設・西南学院・福岡大濠 等）は、限られた100文字を使う価値が低いため意図的に除外しています。これらの学校のコースはアプリ内には引き続きすべて実装されています。

## 更新方法

内容を変えたい場合はこの下の `.txt` ファイルを直接編集し、App Store Connect の該当欄に貼り付けてください。
