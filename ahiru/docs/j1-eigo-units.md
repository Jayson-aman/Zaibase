## 1. 英語の文のしくみと書き方

1. 語順カードで文を組み立てる — I / play / tennis のカードを「だれが・どうする・何を」の順に並べて、文の骨組みを体で覚える
2. 日本語と英語の語順くらべ — 「私は毎日テニスをします」と I play tennis every day. を見くらべ、動詞の位置と「時」の置き場所のちがいを知る
3. 大文字とピリオドのルール — 文頭・I・人名・国名・曜日・月は大文字、文末はピリオド。どれを大文字にするかを見分ける
4. 疑問符・コンマ・感嘆符の使い方 — ? と ! と , の置き場所。Yes, I do. の Yes のあとのコンマ、呼びかけのコンマ
5. アポストロフィ①：短縮形のつくり方 — I'm・you're・don't・can't・it's・let's で、どの文字が消えてアポストロフィになるか
6. アポストロフィ②：'s のはたらき — Tom's bag（持ち主）と He's / It's（is の短縮）の見分け方
7. スラッシュ読み入門 — My friend / lives in Osaka / now. のように意味のかたまりで切り、前から順に読む

## 2. be動詞のつかいどころ

8. be動詞のあとに来る語：名詞・形容詞・場所 — I am a student. / She is kind. / He is in the park. の三つの型
9. You are で相手に話しかける — You are kind. / You are a good singer. などのほめ言葉と、You are ~? の確認
10. This is / That is：近いもの・遠いものを指す — This is a pen. / That is a bike. 近くと遠くで this と that を選ぶ
11. These are / Those are：複数のものを指す — These are apples. / Those are birds. 名詞が複数形になることとセットで覚える
12. He is / She is：人を紹介する — This is Ken. He is my friend. / She's a teacher. 男女で he と she を選ぶ
13. We are / They are：グループを言う — We are classmates. / They are my cousins. 主語が複数のとき are を使う
14. 気持ち・体調を言う be動詞の文 — I'm hungry. / I'm tired. / I'm happy. / Are you OK? 気持ちを表す形容詞

## 3. 一般動詞と日常の動作

15. 毎日の動作のことば①：学校でする動作 — go to school / study / read / write / listen / speak の使い方
16. 毎日の動作のことば②：家でする動作 — get up / eat / drink / wash / brush / watch / cook / sleep
17. 毎日の動作のことば③：外で遊ぶ・運動する動作 — run / walk / swim / ride / jump / play
18. 好き・ほしいを伝える動詞：like・love・want・need — I like ~. / I love ~. / I want ~. / I need ~. の意味の強さのちがい
19. have のいろいろな意味 — 持っている・飼っている・食べる（have lunch）・授業がある、の使い分け
20. 動詞のあとに前置詞が必要な表現 — listen to / look at / talk to / wait for / come from の組み合わせ
21. 主語が and でつながるとき — Tom and I play ~. / My mother and father work ~. 主語が複数になるときの動詞の形

## 4. 名詞・数・もちもの

22. 持ち主を言う文：Tom's と my — This is Tom's. / That is my sister's. 人の名前に 's をつける言い方
23. many・much・a lot of：「たくさん」の使い分け — 数えられる名詞には many、数えられない名詞には much、どちらにも a lot of
24. this・that・these・those を名詞の前に置く — this book / that dog / these boys / those cars。指す語と名詞の形をそろえる
25. a・the・my・this は並べて使えない — × a my book / ○ my book。名詞の前に置く語の選び方
26. 前に出た名詞を it・they・him・her で受ける — I have a dog. It is cute. / I like Ken. He is nice. 同じ語をくり返さない工夫
27. 名前の言い方と敬称 — Taro Yamada（名→姓）の順、Mr. / Ms. / Mrs. の使い分け、呼びかけ

## 5. 疑問詞でたずねる

28. What：「何」をたずねる文の作り方 — What is this? / What do you like? で「疑問詞＋疑問文の形」を作る手順
29. What＋名詞：What color / What sport / What subject — What color is ~? / What sport do you like? 名詞をつけてしぼりこむたずね方
30. What time・What day・What date の使い分け — 時刻・曜日・日付をたずねる3つの形と答え方
31. Where：場所をたずねる — Where is ~? / Where do you live? 答えは場所を表す語句
32. When：時をたずねる — When is your birthday? / When do you get up? 答えは時を表す語句
33. Who：人をたずねる — Who is that boy? / Who's your favorite singer? 答えは人
34. How：ようす・方法・年れい・身長をたずねる — How are you? / How do you go to school? / How old ~? / How tall ~?
35. How many と How much：数と量・ねだんをたずねる — How many books do you have? / How much is this? 答え方のちがい
36. 答えの文から疑問詞を選ぶ — It is a cat. → What / In the park. → Where。下線部をたずねる問題の入口

## 6. can・命令・さそい・There is / There are

37. can の否定：can't と cannot — I can't swim. / He cannot run. 否定の形と、動詞はそのままの形
38. Can you ~? で頼む・Can I ~? で許可を求める — Can you open the door? / Can I use your pen? 「できる」以外の can
39. Can ~? への答え方 — Yes, I can. / No, I can't. / Sure. / Sorry, I can't. 場面に合う返事の選び方
40. Be 〜. の命令文 — Be quiet. / Be careful. / Don't be late. be動詞の命令文の形
41. How about ~? でさそう・意見をきく — How about lunch? / How about you? 相手の考えをたずねる言い方
42. さそいへの返事：受ける・ことわる — Sounds good. / Sure. / I'm sorry, but I can't. ことわり方のマナー
43. There is / There are の形 — There is a book. / There are two books. 後ろの名詞が単数か複数かで選ぶ
44. There is / are ＋ 場所：どこに何があるか — There is a cat under the table. 場所を表す語句の置き場所
45. There is / are の否定文 — There isn't a park. / There aren't any apples. any の使い方
46. Is there ~? / Are there ~? とその答え方 — Is there a bank near here? — Yes, there is. / No, there isn't.
47. There is と It is のちがい — There is a cat. と It is a cat. は何がちがうか（初めて出す／すでに話題の）

## 7. 進行形・過去形のつかいこなし

48. 絵を見て、いま何をしているか言う — He is reading. / They are playing soccer. 絵の状況を現在進行形の文にする
49. 進行形にしない動詞 — know・like・have（持っている）・want は ing 形にしない。I know ~. / I like ~.
50. 過去を表す語句 — yesterday / last night / last week / ~ ago / this morning。過去の文に付く語句
51. 不規則動詞①：形が変わらない・母音だけ変わる動詞 — cut / put / read（読み方が変わる） と come-came / run-ran / sit-sat / get-got
52. 不規則動詞②：-ought・-aught になる動詞 — buy-bought / think-thought / bring-brought / teach-taught / catch-caught
53. 不規則動詞③：語尾が -t になる動詞と -ew になる動詞 — keep-kept / sleep-slept / feel-felt / know-knew / draw-drew / grow-grew / fly-flew
54. 不規則動詞④：よく使う動詞の総点検 — go-went / do-did / see-saw / eat-ate / make-made / take-took / write-wrote / have-had
55. What did you do? 過去について疑問詞でたずねる — What did you do yesterday? / Where did you go? 答え方は過去形の文
56. was・were で過去のようすを言う — It was sunny. / I was at home. / They were happy. 天気・気持ち・場所
57. 現在・過去・進行形を見分ける — 動詞の形と時を表す語句から、文がいつのことかを判断する

## 8. 前置詞とつなぎ言葉

58. with・by・for・about のはたらき — with a pen（道具）/ by bus（手段）/ for you（相手）/ about Japan（話題）
59. to・from・of のはたらき — to Osaka（行き先）/ from Kyoto（出どころ）/ a picture of my family（〜の）
60. and と but：同じ向き・反対向きのつなぎ — I like dogs and cats. / I like dogs, but I don't have one.
61. or と so：選ぶ・結果を言うつなぎ — Tea or coffee? / It was rainy, so I stayed home.
62. つなぐ語を選ぶ練習：and・but・or・so — 文の意味から、4つのつなぎ言葉のどれを入れるかを判断する
63. 時を表す語句は文の最後に置く — I play tennis on Sunday. / I get up at six every day. 語句の置き場所

86. 読解⑤：対話文を読む — 誰が何を言ったかを整理し、問いに答える
87. 読解⑥：表・メニューから情報を読み取る — 時刻表・メニュー・予定表から必要な数字を探す
88. 読解⑦：代名詞が指すものをさがす — it / they / he / she / this が何を指すか、前の文から探す手順
