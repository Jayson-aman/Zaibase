# 小2・社会（生活科のまち・はたらく人・くらし）単元一覧（120単元）

ID は `u120_e2_shakai_001`〜`120`。1単元に1つのことだけを教える。漢字は小2までの配当（小1の80字＋小2の160字、計240字）に収め、小2の漢字には初めて出るところで読みを添える。ほかの字はひらがな。ひらがなは文節ごとに分かち書き（小1国語・小2国語・小2算数と同じ）。
各単元に：導入・動く図解（7枚以上）・具体例・「自分の言葉で言ってみよう」・ひっかけ。「なぜそうなるのか」と、確かめ（見直す手順）の節を必ず入れる。
範囲は学校の小2（生活科：学校・まち・店・はたらく人・のりもの・みんなの場所・きまり・あんぜん・きせつ・そだてる・家ぞくと自分）で、中学受験の社会の土台。小3以降の内容（東西南北のほうい・地図記号の読み書き・市の様子・農家や工場の仕事・消防や警察のしくみ・昔の道具）、都道府県や日本の地形・気候・統計・歴史の人物と年号は入れない。
地図は「上・下・右・左・前・後ろ」と、ものの位置を絵で表すところまで（小3の地図記号・ほういは次の学年）。実在の店・会社・人・地名は出さない。年号・統計の数字は書かない（数は「たとえば」と断る）。
小3社会（`docs/e3-shakai-units.md`）とは、題も内容も重ならない（小3は市のようす・農家・工場・店のくふう・消防と警察・昔のくらし）。小2は「見る・さわる・体験する・やくそくを知る」まで。
