# 小2・英語（外国語活動の前段）単元一覧（50単元）

ID は `u120_e2_eigo_001`〜`050`（セル名 `e2-eigo`）。`examType: 'chugaku'`・`studyPeriod: '小2'`・教科 `eigo`・order は `250001`〜`250050`（既存の最大は 240012。230001〜230012 は立命館の社会、240001〜240012 は立命館の英語が使用中なので避けた）。1単元に1つのこと（1〜4個のことば、または1つの言い方）だけを教える。
漢字は小1・小2の配当（240字）に収め、小2の漢字には初めて出るところで（読み）を添える。ひらがなは文節ごとに半角スペースで分かち書き（小1・小2の国語・算数・理科と同じ）。題は小2の漢字もひらがなにする。「えいご」「にほんご」はひらがな。英語（日本語の中に出る英単語・例文）は、小学校の外国語活動の基本の表現だけで、例文は6語まで。**文法の用語は使わない**。
各単元に：導入・動く図解（7枚以上）・例題（なぜそうなるか・たしかめ）・「自分の言葉で言ってみよう」・ひっかけ。「聞く・まねする・言う・使う」が中心。カタカナの音は「およその目安」と断る。
範囲は小2の子が、友だちや先生と短い会話を聞きまねして言えるところまで。小3以降の内容（He/She の文・What time is it?・月の名前・職業・道あんない・過去の話・文を書く練習・4本線）は入れない。

## 既存の英語単元との関係（重ならない工夫）
- 小1の英語（音・あいさつ・色・数・動物・食べ物のことばそのもの）は、この小2では「ことばの練習」ではなく**使う場面**（きもちを言う・じこしょうかい・すき・できる・数と色をたずねる）で扱う。1〜10の数と基本の色のことばは小1の範囲として、ここでは11から先と、たずねる言い方に絞る。
- 小3の英語（`u120_e3_eigo`、120単元）・小4（`new20_e4_eigo` ほか）と題は1つも同じにしない（全題を機械で照合する）。話題は重なるが、小2は「1つの言い方を聞きまねして言う」ところまで。
- 小2の一覧（教科書タブの「🌱 小2の 英語」を想定）に出す。ふつうの単元の一覧には混ざらない。

## 先に決めておくこと
- 「I can ~.」「Can you ~?」は小2の「できる」の章で、決まった言い方として聞きまねして言うだけにする（文の仕組みの説明はしない）。小3の一覧（`e3-eigo-units.md`）は Can you ~? を小4扱いにしているが、小2のこのセルでは指示により含める。重複の整理は結線時に呼び出し側が判断する。
- 「英」は小4なので「えいご」。「語」は小2だが、題・説明では使わない。
- 年れいの例は seven・eight のみ。自分の年を決めつけない。

## 1. きもち・あいさつ（1〜5）

3. うれしい・かなしい — I'm happy. I'm sad.
4. おなかが すいた・ねむい・つかれた — I'm hungry. I'm sleepy. I'm tired.

## 2. じこしょうかい（6〜10）

## 3. すき（11〜17）

## 4. できる（18〜23）
