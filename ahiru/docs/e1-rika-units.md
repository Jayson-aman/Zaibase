# 小1・理科 単元一覧（120単元）

ID は `u120_e1_rika_001`〜`120`（学年・教科ごとに連番）。学校では「生活科」の自然・季節・生き物・もの・安全の内容にあたる。1単元に1つのことだけを教える。ひらがな中心、漢字は小1の80字だけ（読みは不要）。ひらがなは文節ごとに半角スペースで分かち書き（小1・国語／算数と同じ）。
各単元に：導入・動く図解（7枚以上）・例題（なぜ・たしかめ）・ひっかけ・「じぶんの ことばで いってみよう」をつける。「なぜそうなるのか」を、見える事実から言う。
範囲は小1の生活科レベル（中学受験の理科の土台）。**小2以上の内容は入れない**：星・月の動き、天気の変化の仕組み、水のすがた（ふっとう・じょうはつ）、電気・じしゃく・光の進み方・音のふるえの仕組み、てこ・ふりこ、からだの仕組み（ほね・きん肉）、光合成・発芽の条件・食物れんさ、こん虫のからだのつくり（頭・むね・はら、あし6本）、「町たんけん」の公共しせつ、など。小1は「見る・さわる・においをかぐ・くらべる」の体験と、季節のうつりかわり、あんぜんが中心。
既存のセル（中学受験×小1×理科）に単元は無い（確認済み）。ほかのセル（小3理科・小4理科）とは題が重ならない。
