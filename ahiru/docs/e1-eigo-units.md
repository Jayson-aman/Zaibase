# 小1・英語（外国語活動の前段）単元一覧（50単元）

ID は `u120_e1_eigo_001`〜`050`（セル名 `e1-eigo`）。`examType: 'chugaku'`・`studyPeriod: '小1'`・教科 `eigo`・order は `220001`〜`220050`（英語の教科内では未使用。ほかの教科の 220xxx〔立命館・理科〕とは教科がちがうので重ならない）。学校の教科にはまだ無い学年なので、小3の外国語活動の「前段」として、**英語の音に親しむ**ことだけをねらう。1単元に1つのこと（1〜4個のことば、または1つの言い方、アルファベットは5〜6文字）だけを、**聞いて・まねして・言う**ところまで。
**書き写し・文の読み書きはしない**。アルファベットは**大文字の名前（エー・ビー・シー…）を聞いて言う**だけ（小文字・文字の音〔フォニックス〕・書き方は扱わない）。**文法用語を使わない**（名詞・動詞・複数形・疑問文・主語・過去形など）。
ひらがな中心、漢字は小1の配当80字だけ（読みは不要）。ひらがなは文節ごとに半角スペースで分かち書き（小1・国語／算数／理科と同じ）。英語のことばの前後も文節のくぎりとして空白をあける（例：「Good morning. と いって みよう。」）。題も分かち書きのまま。
各単元に：導入・動く図解（7枚以上）・例題（なぜ・たしかめ）・ひっかけ・「じぶんの ことばで いってみよう」。ことばの音のカタカナ表記は「およその目安」と断る。
範囲は「聞く・まねする・言う」。**小3以降の内容は入れない**（How old are you?・Do you like ~?・Can you ~?・月の名前・曜日・天気・職業・道あんない・He/She の文・過去の話・文を書く練習）。**小2の英語（別のセル）とも重ならないよう**、小1は「ことばを1〜3個ずつ」「あいさつと 名前と 気もち」「かず1〜10」「いろ8つ」「どうぶつ・たべもの・身のまわりの もの」「大もじの なまえ」に限る。
既存のセル（中学受験×小1×英語）に単元は無い（確認済み：`studyPeriod: '小1'` の単元は `u120_e1_*` の 国語・算数・理科・社会 だけ）。小3・小4の英語（`u120_e3_eigo_*`・`u120_e4_eigo_*`）とは、同じ題（Good morning. など）があっても学年がちがうので別のセル（同一セル内の題の重複は無い）。

## 1. えい語と なかよし（1〜5）
1. えい語って どんな ことば？ … 日本語と ちがう ことば。せかいの たくさんの 国の 人が つかう。まずは「きく・いう」から。（ことばの 例は hello だけ）
2. まわりの えい語 さがし … ふくろ・ふく・かんばんで 見かける えい語。カタカナの ことばと えい語の 音は すこし ちがう（juice と ジュース）。
3. えい語の 音を きこう … ひとつずつの ことばを よく きく。おなじ 音・ちがう 音を きき分ける（dog と dog・dog と cat）。
4. まねして 声に 出そう … くちの 形・大きな 声・はっきり。先生や 音声の まねを して いう。
5. ジェスチャーで つたえよう … 身ぶりと 顔で 気もちを つたえる。ことばが わからなくても つたわる（うなずく・手を ふる）。

## 2. あいさつ（6〜12）
6. Hello. と Hi. … 会ったときの あいさつ。Hello. は だれにでも、Hi. は なかよしの 友だちに。
7. Good morning. … 朝の あいさつ。
8. Good afternoon. … 昼すぎの あいさつ。（時こくは 数で きめない）
9. Good night. … ねる まえに いう あいさつ。
10. Goodbye. と Bye. … わかれの あいさつ。手を ふる。
11. Thank you. … ありがとう。かえしの You're welcome. は 先生の ことばを きくだけ。
12. Sorry. … ごめんなさい。

## 3. なまえと きもち（13〜18）
13. Yes. と No. … 「はい」と「いいえ」。うなずく・くびを ふる ジェスチャーと いっしょに。
14. I'm Ken. … 名前を いう。じぶんの 名前に おきかえる。
15. What's your name? … 名前を きく・こたえる。きいた あとに I'm ~. で こたえる。
16. How are you? … 「げんきかな」と きく あいさつ。I'm fine. で こたえる。
17. I'm happy. と I'm sad. … うれしい・かなしい。
18. I'm hungry. と I'm sleepy. … おなかが すいた・ねむい。

## 4. かず（19〜23）
19. one・two・three … 1〜3 の いいかたと きき取り。ゆびで かぞえる。
20. four・five・six … 4〜6。
21. seven・eight … 7と8。
22. nine・ten … 9と10。
23. ゆびで かぞえて いって みよう … 1〜10 を ゆびで かぞえながら いう。ふくしゅう。

## 5. いろ（24〜27）
24. red と blue … 赤と青。
25. yellow と green … 黄いろと みどり。
26. pink と orange … ももいろと だいだいいろ（オレンジ）。
27. black と white … 黒と白。

## 6. どうぶつ（28〜32）
28. dog と cat … 犬と ねこ。
29. bird と fish … とりと さかな。
30. rabbit と monkey … うさぎと さる。
31. lion と elephant … ライオンと ぞう。
32. どうぶつの なきごえ … dog は woof woof、cat は meow、cow は moo、duck は quack quack。日本語の 聞こえかたと ちがう。

## 7. たべもの・のみもの（33〜37）
33. apple と banana … りんごと バナナ。
34. grapes・peach・melon … ぶどう・もも・メロン。
35. milk と juice … ぎゅうにゅうと ジュース。
36. bread と rice … パンと ごはん。
37. I like ~. … すきな ものを つたえる。milk・juice・bread・rice で いう。

## 8. みのまわりの もの（38〜40）
38. pencil と pen … えんぴつと ペン。
39. book と bag … ほんと かばん。
40. desk と chair … つくえと いす。

## 9. からだと うた（41〜44）
41. eyes・ears・nose・mouth … 目・耳・はな・口。さわって いう。
42. head・shoulders・knees・toes … あたま・かた・ひざ・つまさき。
43. リズムに のって いおう … 手を たたきながら、ことばを リズムで いう（1〜5 の かずで れんしゅう）。
44. うたって あそぼう … Head, Shoulders, Knees and Toes の うたと ふり。あそびの やくそく。

## 10. アルファベットの なまえ（45〜50）
45. アルファベットって なあに？ … 26もじ。大もじ。ABC の うたで ながれを きく。
46. A・B・C・D・E … 5つの もじの なまえ（エー・ビー・シー・ディー・イー）を きいて いう。
47. F・G・H・I・J … 5つ。
48. K・L・M・N・O … 5つ。
49. P・Q・R・S・T … 5つ。
50. U・V・W・X・Y・Z … 6つ。
