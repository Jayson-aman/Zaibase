# 2.2.9 に入れるもの（作業メモ）

継続率の改善（2.2.8 公開時点：翌日12%・7日後1〜2%）。コードはもう入っている（2.2.8 のビルドに含めるか 2.2.9 にするかはビルドを出す時に決める）。

## ① はじめの5問
- 1問も答えていない人のホーム最上段に、学年（小4〜6／中1〜3）を選んで「はじめる」だけの案内を出す。
- 算数・数学の基礎問題を5問（`/quiz/sansu?...&difficulty=basic&grade=..&limit=5`）。5問に収まるよう、連続不正解でも基礎問題を足さない。
- 実装：`components/StudyStartCard.tsx`、`app/quiz/[subject].tsx`（`limit` パラメータ）。

## ② 連続日数と1日の目標（5問）
- 答えた問題数を日本時間の日付ごとに記録（`store/studyStreak.ts`、キー `@ahiru_study_days`。ログイン／ログアウトで人ごとに分かれる）。
- ホーム上段：連続日数・今日の進み・直近7日。目標前なら「あとN問やる」（教科は日替わり）。
- 結果画面：連続日数と目標の達成を表示。
- 目標の数は `DAILY_GOAL`（現在5）。

## 実機で確認すること
1. 新規インストール → 受験種別 → ホームに緑の「はじめの5問」が出る → 5問で止まる（8問に伸びない）。
2. 5問終えると結果画面に「🔥 1日れんぞく！ ✅ 今日の目標を達成」。ホームがオレンジの連続日数カードに変わる。
3. 翌日開くと連続が続いている（日本時間0時で切りかわる）。2日あけると 0 から。
4. ログアウト→別アカウントで入ると、前の人の連続日数が見えない。
