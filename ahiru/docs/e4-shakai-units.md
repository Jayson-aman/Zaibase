# 小4・社会 単元一覧（120単元）

ID は `u120_e4_shakai_001`〜`120`。1単元に1つのことだけを教える。漢字は小1〜小4の642字に収め、小4の字には初めて出るところで読みを添える。
各単元：導入・動く図解・具体例・「自分の言葉で言ってみよう」・書いて答える問題。「なぜそうなるのか」と、確かめ（地図や資料を見直す手順）の節を必ず入れる。
範囲は学校の小4社会（中学受験の土台）。小5以降の内容（日本の気候・地形の詳しい統計・産業の統計・歴史の人物と年号・憲法と政治のしくみ）は入れない。都道府県は1県1単元にせず、地方ごとに数単元で名前・位置・県ちょうしょざいち・特色を扱う（47都道府県を必ず入れる）。
