# 小1の漢字80字：書き順データの確認

対象：`data/kanji-strokes.ts`（Hanzi Writer の日本語データ hanzi-writer-data-jp から作成）。

## 方法
別の公開データ **KanjiVG**（日本の学校の筆順にそった書き順。CC BY-SA）と、1画ずつ照らし合わせた。KanjiVG は確認にだけ使い、アプリには入れていない。

1. 80字ぶん、両方の線を取る（組み込みデータは中心線、KanjiVG は線の形）。
2. 各字の大きさをそろえ、各画を12点に分ける（始点から終点の順）。
3. 組み込みデータの各画 i について、KanjiVG の各画 j との「点どうしの平均のきょり」を出す。
4. 各画 i に、いちばん近いのが j = i（同じ番号）の画か確かめる（ずれは0.01より小さいことを条件にした）。

## 結果
- 画数：80字すべて、正しい画数と一致。
- 位置・向き・順番：80字すべて、各画が同じ番号の画にいちばん近い（ちがう画に近いものは 0件）。
- 感度：この方法は、となりあう2画を入れかえると、全ての場合（100%）で見つけられた。

## 追加の確認（2026/11/5）
- 文部科学省「筆順指導の手びき」（1958年）の**原本の本文は、この環境から読めなかった**（国立国会図書館の画像資料で、オンラインで本文を取れない）。そのため、本文との1字ずつの照合はしていない。
- 代わりに、**学校の筆順がまちがえやすい字**について、書きはじめの位置から、手びきの定説どおりの順になっているかを確かめた：右（ノ→一→口）、左（一→ノ→工）、上（縦→短い横→長い横）、下（横→縦→点）、九（ノ→乙）、力（乙→ノ）、王、田（縦→横折→縦→横→横）、生、火。**すべて一致した。**
- 手びきには「広く使われる筆順が2つ以上ある字」の例として「上」「点」「店」などがある（検索で確認）。今回の「上」は、よく使われる筆順（縦→短い横→長い横）になっている。

## まだ確かめていないこと
- 文部科学省「筆順指導の手びき」の本文と、1字ずつ照らしたわけではない（2つの公開データが一致した、という確認）。
- 学校や先生によって、筆順がちがう字がある（たとえば「必」「無」）。小1の80字には、そうした字は含まれないと考えているが、確かではない。
