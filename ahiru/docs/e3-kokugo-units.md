# 小3・国語 単元一覧（120単元）

ID は `u120_e3_kokugo_001`〜`120`。1単元に1つのことだけを教える。漢字は小3までの配当（小1〜小3の440字）に収め、小3の漢字には初めて出るところで読みを添える。
各単元に：導入・動く図解・具体例・「自分の言葉で言ってみよう」・書いて答える問題。「なぜそうなるのか」を必ず書く。
範囲は学校の小3国語（中学受験の土台）。小4以降の内容（敬語の使い分け・段落の要約・古文・漢文・文法用語の「助動詞」など）は入れない。ローマ字は小3で習うので入れる。
漢字の単元（1〜8、9〜28）は、括弧の中の漢字を、そのまま、1字も欠かさず・重ならずに使う（小2の160字は単元1〜8、小3の200字は単元9〜28）。
